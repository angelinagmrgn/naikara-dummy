# NAIKARA — AI Career Assistant (Landing Page + Auth Pages + Supabase)

## Struktur File
- `index.html` → Halaman utama (Landing Page).
- `register.html` → Halaman Daftar Akun (`/register`), default tab **Daftar Akun**.
- `login.html` → Halaman Masuk (`/login`), default tab **Masuk**.
- `js/supabase-config.js` → Tempat menaruh `SUPABASE_URL` dan `SUPABASE_ANON_KEY`.
- `supabase-schema.sql` → Script SQL untuk membuat tabel `profiles` otomatis di Supabase.
- `assets/` → Simpan file gambarmu di sini (`logo.png`, `mascot-hero.png`, `pesona-karier.jpg`, `terkurasi.jpg`, `ai-career.jpg`, dan opsional `mascot-login.png`).
